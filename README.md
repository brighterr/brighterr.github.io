# Yuheng Zhang's Academic Homepage

Source for [brighterr.github.io](https://brighterr.github.io), the academic homepage of Yuheng Zhang (张宇衡), an undergraduate researcher at Renmin University of China.

## Local development

```bash
brew install ruby@3.2
bundle install
bash run_server.sh
```

The site is available at `http://127.0.0.1:4000`.

## Content

- Site settings and public contact information: `_config.yml`
- Homepage content: `_pages/about.md`
- Navigation: `_data/navigation.yml`
- Personal styling: `assets/css/main.scss`
- Local images: `images/`

The public site intentionally excludes the phone number, birth date, and original resume files.
